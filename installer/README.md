# Kinematics Studio Windows Installer

This folder contains the production Inno Setup installer project for Kinematics Studio.

## Required software

- Windows 10 or later
- Inno Setup 6.x
- Kinematics Studio release artifacts generated by the release pipeline

## Generated build configuration

The release pipeline generates:

```text
installer/generated/build.issinc
```

This generated file contains the release version, portable source folder, installer output folder, launcher name, publisher metadata and future installer integration values.

`build.issinc` is a temporary internal build file. It is regenerated every build and should never be edited manually.

The generated file is used by the release pipeline while release staging is available. It is not a distributable release artifact and is not included in shipped release manifests.

## Windows installer GUID strategy

`UpgradeCode` identifies the Kinematics Studio Windows installer lineage. It remains stable across all releases so future installers can recognize previous installations.

`ProductCode` is managed independently from `UpgradeCode`. It identifies the current major installer product identity. For a future major release that intentionally requires a new installed-product identity, generate a new `ProductCode` in the release builder while preserving the existing `UpgradeCode`.

## How to compile

The release builder compiles the Windows installer automatically when Inno Setup is installed.

Run:

```text
python tools\release\build_release.py
```

The release build generates `installer/generated/build.issinc`, builds `Portable.zip`, and then attempts to compile `installer/KinematicsStudio.iss`.

ISCC detection runs in this order:

1. `shutil.which("iscc")`
2. `C:\Program Files\Inno Setup 6\ISCC.exe`
3. `C:\Program Files (x86)\Inno Setup 6\ISCC.exe`

If ISCC is not found, the release build still completes. The portable release, documentation, manifests and checksums are produced, and the manifest records the Windows installer as `UNSUPPORTED_ON_THIS_HOST`.

If ISCC returns an error, the release build still completes. The manifest records the installer build as `FAILED` and the compiler output is saved to the installer build log.

The compiler output is always written to:

```text
Windows/Installer/InstallerBuild.log
```

For manual diagnostic compilation, run it while the release staging directory referenced by `installer/generated/build.issinc` still exists.

Command line:

```text
ISCC.exe installer\KinematicsStudio.iss
```

## Expected output

The installer output directory and filename are defined by `installer/generated/build.issinc`.

## Assets

The generated build configuration points Inno Setup to the active application icon. If the application branding icon is unavailable, the release builder uses the installer-local placeholder icon.

Wizard artwork in `installer/assets/` is placeholder artwork until final production branding artwork is supplied.
